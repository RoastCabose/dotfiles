# Instructions for Agents

These are instructions for agents running under Roast.

- When writing commit messages, NEVER add your agent name as co-author
- NEVER modify the changelog or files that are auto-generated
- When making technical decisions, do not give weight to development time. Instead, prefer quality, simplicity, robustness, scalability, and long term maintainability
- ALWAYS communicate in as few words as possible without losing precision.
